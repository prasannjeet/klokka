# Icons and link cards

- `src/app/icon.tsx` (SVG) is the favicon; `favicon.ico` (16/32/48) and `icon1.png` (96) next to it are the same
  mark as files, transparent, for clients that skip SVG icons. Regenerate from the repo root with Pillow:
  `python3 -c "from PIL import Image;m=Image.open('docs/brand/final/klokka-mark-heavy.png').convert('RGBA');m=m.crop(m.getbbox());exec('def g(n,f,bg=(0,0,0,0)):\n k=n*f/max(m.size);a=m.getchannel(\'A\').resize((round(m.width*k),round(m.height*k)),Image.LANCZOS);p=Image.new(\'RGBA\',a.size,\'#FF006E\');p.putalpha(a);o=Image.new(\'RGBA\',(n,n),bg);o.alpha_composite(p,((n-a.width)//2,(n-a.height)//2));return o');g(96,.94).save('apps/landing/src/app/icon1.png');i=[g(n,.94) for n in (48,32,16)];i[0].save('apps/landing/src/app/favicon.ico',sizes=[(48,48),(32,32),(16,16)],append_images=i[1:])"`
- Link cards are `/og/<id>-<locale>.jpg`, drawn at build time by `pageCard` in `src/lib/brand-image.tsx` over the
  artwork in `src/assets/og/` (1200 px wide, JPEG q82, resized from `docs/brand/social/backgrounds/`).

# Adding a page

Every page but the homepage is one entry in `src/lib/pages/registry.ts` plus one copy file; routes, metadata,
hreflang, JSON-LD, the sitemap, the footer, `llms.txt` and the link card all follow from those two
(`docs/DECISIONS.md` D18).

1. **Registry entry** in `src/lib/pages/registry.ts`: `id` (add it to `PageId`), `kind`, `path` for `sv` (ASCII
   slug, served at the root through a rewrite) and `en` (served under `/en`), `parent` (breadcrumbs), `footer`
   group or `null`, `lastmod` and the card `background`. The file stays import-free: `next.config.ts` reads it.
2. **Copy** in `src/lib/i18n/pages/<id>.ts`: `sv` as `as const satisfies` the kind's type (`PageCopyBase`,
   `GuideCopy`, `ToolCopy`, `TableCopy`), `en: PageCopyOf<typeof sv>`; register it in `src/lib/i18n/pages/index.ts`.
   Links inside copy are `[label](page:<id>)` or `[label](https://...)`. Facts and keywords come from the page's brief
   in `docs/research/seo/page-briefs.md`.
3. **Layout**: the kind picks the component in `src/app/[lang]/[...slug]/page.tsx` (`ProductPage`, `ToolPage`,
   `GuidePage`, `IndustryPage`, `TablePage`, `LegalPage`). A new kind needs a new component and a case there; a
   registered page without a layout fails the build.
4. **Tests**: `test/pages.test.ts` runs over every registered page in both languages: unique rooted paths, parents
   that exist, a rewrite per Swedish path, title <= 60, description <= 155, card eyebrow <= 20 and title <= 45, no
   empty string and no em dash, no pricing words, every `page:` link registered, the same shape in sv and en, and
   "personalliggare" kept out of the title and H1 of anything but a guide. Add one page per new kind to `SUBPAGES`
   in `e2e/helpers.ts` for the layout run (`npm run test:layout`).
5. **Card**: nothing to do. `/og/<id>-<locale>.jpg` is drawn at build time from the copy's `card` text on the
   entry's background, and `og:image` points at it.

# Timesheet template files

`public/downloads/*` (xlsx, PDF and preview PNG per language) are generated by `scripts/templates.ts` from the
template page's copy: `npm run templates -w @klokka/landing` (needs `pdftoppm`). The output is deterministic (fixed
metadata dates), so a re-run without a copy change gives the same bytes; commit the files whenever they change.
`test/pages.test.ts` checks they exist, stay under 200 KB and that the preview has the size the page declares.
