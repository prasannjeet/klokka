# Map location picker, production release v1.6.0 (CHQ-163)

Released 2026-10-06 at the owner's request, after the staging APK was checked on the test phone.

## What changed

- Android: choosing a job's place opens a full-screen map (Google Maps through `expo-maps`; Apple Maps on iOS,
  not built yet, see [IOS_TESTING.md](../IOS_TESTING.md)). Search through the API, pick a result, move the map to
  adjust the pin (reverse geocoded by the API), "Use this place". Fixed layout: typing never resizes the screen.
- Android: the small map on job cards and in the job sheet loads. React Native's Android Image forwards request
  headers only from an array source, so the bearer was dropped and every `map.png` answered 401 since CHQ-156.
- The APK carries the Maps SDK for Android key "Klokka Android maps" (Google Cloud project
  `gen-lang-client-0540235986`, restricted to `se.klokka.app` + the release SHA-1); CI refuses to build without it.
  The owner enabled the Maps Static API for the server key the same day.
- Web: unchanged picker; the interactive web map is CHQ-164.

## Deployment evidence

- Tag `v1.6.0`; [release run](https://github.com/prasannjeet/klokka/actions/runs/37511996115) green on the first
  attempt (images, production APK/AAB, Play upload).
- Production database dumped right before rollout (`.agents/local-credentials/klokka-prod-before-v1.6.0-*.dump`,
  restore catalog checked). Coolify configurations saved before and after: only the image tag changed.
- Order: API, web, landing, all `:v1.6.0`. No migration (schema stays at V5, "up to date"). Jobs and entries 6 and
  6 before and after.
- API readiness, web health, landing, Logto discovery 200; `/v1/me` 401 without a token. Landing indexable on `/`
  and `/en`; IndexNow accepted the 46 sitemap URLs (200). Production checks were read-only.

## Android and Google Play

- APK `prod/klokka-v1.6.0.apk` (and `prod/klokka-latest.apk`), AAB `prod/klokka-v1.6.0.aab` on Nexus.
- Play: versionCode 13 uploaded by the release job, set `completed` on internal testing and staged as a `draft` on
  closed testing (`alpha`). Public rollout still waits on CHQ-161.
