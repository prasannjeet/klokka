# Android keyboard fix, production release v1.6.3 (CHQ-175)

Released 2026-10-07 at the owner's request, after the staging APK was checked on the test phone.

## What changed

- Android: a text field in a sheet stays whole above the keyboard on every phone size, and the sheet keeps its
  header on screen. Inside the native sheet's window `react-native-keyboard-controller` reports no keyboard, so
  `KeyboardAwareScrollView` (CHQ-166, iOS) never scrolled there, while the Compose sheet lifts its content itself.
  On Android the sheet body now shrinks by React Native's keyboard height and scrolls the focused field into view
  (`offsetToReveal`). Verified at 360x640, 390x844, 412x915 and 430x932 dp. iOS is unchanged.
- The `ResolveFlagScreen` test waits for the history query (flaky under CI load in the v1.6.2 run).
