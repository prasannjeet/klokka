# Android button fix, production release v1.6.1 (CHQ-172)

Released 2026-10-07 at the owner's request, after the staging APK was checked on the test phone. It also ships the
owner's CHQ-165 to CHQ-171 work merged since v1.6.0 (iOS scene lifecycle, sheet keyboard handling, tab bar and
refresh fixes, the employer tab restructure with the team calendar, and its web parity).

## What changed (CHQ-172)

- Android: buttons that start disabled react on their whole surface again. React Native on Android (Fabric) sets
  a view's native `enabled` flag from `accessibilityState.disabled` but leaves the key out once it is false, so a
  button that started disabled stayed natively disabled; `TouchTargetHelper` skips disabled views, so only taps on
  the label got through (Repeat's Done, Use this date, Save job). `AppPressable` now remounts when `disabled`
  flips. Verified with a debug build: the button node read `enabled="false"` before and `true` after.
- The job sheet's close button shows on its main page only; sub-pages (Repeat, Starts at, the scope question) keep
  Back, so closing cannot discard the job. Swiping the sheet down still closes it.
