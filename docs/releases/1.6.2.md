# Crash fix, release v1.6.2 to Google Play (CHQ-173, CHQ-174)

Released 2026-10-07 at the owner's request: tag and Google Play only. The servers were not redeployed; production
API, web and landing stay on v1.6.1 (`:v1.6.2` images exist in Nexus for when they are).

## What changed

- Android and iOS: no crash on a cold start once a recurring job was cached (the persisted query cache now tags a
  `Set` like a `Date`; schema 3 drops caches written before) (CHQ-173).
- Home's "working today" counts the same team on both sides (CHQ-174). This part is computed by the API, so it
  reaches users only when the API is deployed at v1.6.2; the v1.6.2 app works against the v1.6.1 API (the contract
  change is a description only).
- iOS: private auth session for sign-in and sign-out; the location prompt in Swedish and English (CHQ-174). Tested
  on a MacBook and iPhone, see [IOS_TESTING.md](../IOS_TESTING.md).

## Evidence

- Tag `v1.6.2`; [release run](https://github.com/prasannjeet/klokka/actions/runs/37650395277) green (images, production
  APK/AAB, Play upload). The commit before it was green on CI (`19c97d4`).
- APK `prod/klokka-v1.6.2.apk` (and `prod/klokka-latest.apk`), AAB `prod/klokka-v1.6.2.aab` on Nexus.
- Play: versionCode 15 `completed` on internal testing and staged as a `draft` on closed testing (`alpha`).
