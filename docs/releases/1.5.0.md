# Calmer UI and recurring-job fixes, production release v1.5.0 (CHQ-162)

Released 2026-10-06 at the owner's request, after staging was checked on the test phone (staging APK from Nexus).

## What changed

- A calmer Nightshift on the web app and Android (D20): Inter headings, smaller type, 12 px corners, grouped lists,
  pink only for the main action. The landing site is unchanged.
- Android: rows, chips and labels no longer overlap (moving layout animations removed; a Pixel 9 Pro XL left them
  25 px off). The job sheet groups place, start time and repeat; repeat uses segmented choices and steppers.
- Recurring jobs (CHQ-159 review): retry key is a canonical request hash (Flyway V5), enum frequency and ordered
  weekdays, series loaded per workspace, the month lock checked once per month, "1 job" singular, and switching
  weekly/monthly asks for the end again on both clients.

## Deployment evidence

- Tag `v1.5.0`; [release run](https://github.com/prasannjeet/klokka/actions/runs/37487912940) green. The APK job
  first hung on a Gradle lock while the host was at its memory cap (OPERATIONS.md section 9) and passed on rerun.
- Production database dumped right before rollout (`.agents/local-credentials/klokka-prod-before-v1.5.0-*.dump`,
  restore catalog checked). Coolify configurations saved before and after; only the image tag changed.
- Order: API, web, landing, all `:v1.5.0`. Flyway V5 applied in 32 ms; `request_payload` stays (nullable) so v1.4.0
  can still be rolled back to. Jobs and entries counted before and after: unchanged (5 and 5); no series existed.
- API readiness, web health, landing, Logto discovery 200; `/v1/me` 401 without a token. Landing indexable on `/`
  and `/en`; IndexNow accepted the 46 sitemap URLs (200). Production checks were read-only; no test data was created.
- Staging before the tag: V5 applied, series created by v1.4.0 read back correctly, a new series created and
  stopped through the app (hash stored, payload null).

## Android and Google Play

- APK `prod/klokka-v1.5.0.apk` (and `prod/klokka-latest.apk`), AAB `prod/klokka-v1.5.0.aab` on Nexus.
- Play: versionCode 12 uploaded by the release job, then set `completed` on internal testing and staged as a
  `draft` on closed testing (`alpha`), as for v1.4.0. Public rollout still waits on CHQ-161.

## Rollback

Previous production tag `v1.4.0`. V5 is additive (a nullable column and a relaxed NOT NULL), so the v1.4.0 API runs
on it. Never restore the pre-release dump over newer user work without a separate recovery decision.
